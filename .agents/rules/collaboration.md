# Collaboration and handoff

- Inspect existing files and Git status before editing. Preserve unrelated user
  changes; commit only files changed for the current task.
- Delegate independent work when it saves time. Give each worker a distinct file
  or module boundary; one integrator reviews the combined result.
- Keep plans proportional to the work. For a longer task, leave a concise handoff
  with the objective, files changed, actual check results, and remaining work.
- Record durable project decisions near the code or in project documentation
  when they affect later work. Do not create a parallel backlog for routine tasks.
- Follow the user's publication workflow when a remote exists. Inspect branch
  policies and required checks before publishing or merging; never invent a
  remote, Git author identity, or permission to bypass review.
