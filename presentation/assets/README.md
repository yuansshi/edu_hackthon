# Presentation artwork

`smart-pants-cover.png` is a generated editorial illustration for the **Smart
Pants team** cover. It is decorative team artwork, not a product screenshot or
evidence of a classroom event. The PNG is 1254 × 1254 with an alpha channel.

Mode: built-in `image_gen.imagegen`, new-image generation, transparent background.
No project API credential was read or used. The selected output was copied into
this repository; its original remains in the Codex generated-images directory.

## Exact generation prompt

```text
Use case: illustration-story
Asset type: editorial cover illustration for an elementary-math hackathon team named Smart Pants; artwork only, no lettering.
Primary request: A friendly pair of forest-green trousers with round spectacles, a subtle clever character expression, posed beside a small pencil and a few elementary regrouping blocks. Charming but sophisticated, useful as the right-hand illustration on a clean presentation cover.
Style/medium: textured cut-paper editorial illustration with restrained flat ink, tactile paper grain, simple organic contours, gentle print imperfections; tasteful contemporary children's education publishing.
Composition/framing: square canvas, complete self-contained character and props, generous clear margins, all elements visible with no edge cropping; no background scene.
Lighting/mood: warm, calm, intelligent, playful.
Color palette: forest green #163C32, chartreuse #DDF174, coral #F58B72, tiny cream details.
Constraints: genuinely transparent background; no words, numbers, letters, labels, logos, watermarks or text. No humans. No shiny 3D plastic rendering, no stock robot, no gradients, no busy detail. Keep the trousers clearly recognizable as trousers rather than a person wearing them.
```
