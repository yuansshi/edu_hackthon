# Learning Strength Discovery

Version 0.1. Original pilot assessment for grades 5–8. This paper or conversation kit has not been validated as a psychological test.

Results cover personality tendencies, concentration, reasoning and learning response, pace and information load, motivation, self-management, confidence and persistence, and interaction preferences.

Use the materials in order:

1. Read the [facilitator guide](facilitator_guide.md).
2. Complete the [24 student prompts](student_assessment.md).
3. Offer the [three activity cards](activity_cards.md).
4. Record responses and context in the [response record](response_record.md).
5. Prepare the [eight-dimension student report](report_template.md), then invite student corrections.
6. Agree on learning arrangements to try. See the [fictional example](example_report.md).

Allow about 25–35 minutes for the baseline walkthrough and report discussion, or split the visit. Optional activity extensions add time. These are unmeasured pilot estimates. Offer pauses, skipped questions, and suitable access supports.

There is no overall score, personality type, IQ, percentile, or measured attention limit. Separate preferences, observations, uncertainty, and adjustments to try. Subject readiness is a separate assessment.

Review the [evidence and limits](evidence_notes.md) before interpreting results. Pilot comprehension, accessibility, burden, and usefulness before making assessment or learning-effect claims.
